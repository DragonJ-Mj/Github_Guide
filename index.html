First Concept

What is GitHub?

GitHub in simple words

GitHub is an online platform where developers can store, manage, share and collaborate on software projects.

Think of GitHub as a combination of:

  • Cloud storage for source code
  • Version control
  • Team collaboration
  • Project management
  • Open-source community
  • Software development platform

GitHub is NOT Git

This is one of the most important concepts beginners should understand.

Git

A version control system installed on your computer.

GitHub

An online platform that hosts Git repositories and provides collaboration features.

Git is the software that allows your computer to communicate with GitHub.

Check whether Git is installed

If Git is installed, you will see something similar to:

Install Git for Windows and use Git Bash, PowerShell or Command Prompt.

macOS

03

Before making commits, configure the name and email associated with your Git commits. 

git config --global user.name "Your Name"


git config --global user.email "[you@example.com](mailto:you@example.com)"

Check configuration

git config --list

Core GitHub Concept

Repositories

What is a repository?

A repository, commonly called a "repo", is the place where a project and its Git history are stored.

A repository can contain:

  • Source code
  • Documentation
  • Images
  • Configuration files
  • README.md
  • .gitignore
  • Git history

Public vs Private

🌎 Public

Anyone can view the repository.

🔒 Private

Access is restricted to people you authorize.

📄 README.md

📄 package.json

Git History

Commits

What is a commit?

A commit is a saved snapshot of your project. Every commit creates a point in the project's history. 

git add .


git commit -m "Add login page"

Good commit messages

  • Add user authentication
  • Fix navbar responsive issue
  • Update README documentation
  • Add database models

Avoid messages like

  • asdf
  • changes
  • update
  • final final
v1 Initial project First commit
v2 Add login Authentication added
v3 Fix bugs Bug fixes
v4 Add dashboard New feature

Pull Requests

What is a Pull Request?

A Pull Request, commonly called a PR, is a request to merge your changes into another branch.

Pull Requests are one of the most important features used by software development teams.

1 Create branch feature-login
→
2 Write code git commit
→
3 Push branch git push

4 Open PR Review
→

Typical Pull Request Review

  • Comments may be added
  • Changes may be requested
  • Automated tests can run
  • Approved code can be merged

Troubleshooting

Merge Conflicts

A merge conflict happens when Git cannot automatically determine which changes should be kept. 

<<<<<<< HEAD


Your version

=======

Another version

>>>>>>> feature-branch

How to resolve a conflict

  1. Open the conflicting file.
  2. Understand both changes.
  3. Choose or combine the correct code.
  4. Remove conflict markers.
  5. Save the file.
  6. Add the file.
  7. Create the merge commit if required.
git add .


git commit -m "Resolve merge conflict"

Very Important

GitHub Security

🔐

Never commit secrets

Keep API keys, passwords and tokens outside your repository.

🔒

Use environment variables

Store environment-specific configuration securely.

🛡️

Enable 2FA

Add another layer of protection to your GitHub account.

👀

Review permissions

Only give collaborators the access they actually need.

🚨 Example of something you should NEVER commit

API_KEY="my-secret-api-key"


DATABASE_PASSWORD="mypassword"
AWS_SECRET_KEY="secret"

Put sensitive values in an appropriate secret/configuration mechanism instead of committing them to source control.

Frequently Asked Questions

GitHub FAQ

Is GitHub the same as Git?

No. Git is a version control system while GitHub is an online platform that hosts Git repositories and provides collaboration tools.

Do I need Git to use GitHub?

Not for every GitHub feature. However, learning Git is extremely useful if you want to work professionally with software repositories.

What is GitHub used for?

GitHub is used for source-code hosting, collaboration, code review, issue tracking, automation, documentation and many other software-development workflows.

What is a repository?

A repository is a project storage location containing files and version history.

What is a branch?

A branch is an independent line of development used to work on changes without directly modifying another branch.

What is a Pull Request?

A Pull Request proposes changes from one branch to another and allows discussion, review, testing and eventually merging.

Can GitHub be used for private projects?

Yes. GitHub supports private repositories.

Can I use GitHub for my portfolio?

Yes. GitHub can be an excellent place to showcase software projects and technical work.
